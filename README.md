# Sistema para Barbearia

Projeto desenvolvido como trabalho para a disciplina **EMPD.2 (Estrutura, Modelagem e Persistência de Dados),** prof. Wild Barreto (a lenda, o grande shogun do conhecimento, o selvagem).

O projeto consiste no desenvolvimento de um sistema para auxiliar no gerenciamento de uma barbearia, aplicando os conceitos abordados durante a disciplina, como **estrutura, modelagem e persistência de dados**.

## Tecnologias

- Python
- MySQL

## Arquitetura

O projeto utiliza o padrão arquitetural **MVC (Model-View-Controller)**, separando as responsabilidades da aplicação entre a camada de dados, a interface e o controle das regras de negócio.

## Disciplina

**Estrutura, Modelagem e Persistência de Dados**
